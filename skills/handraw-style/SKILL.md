# 手绘风格提示词库（Hand-drawn Style Prompter · CrabPaw 适配版）

来源：[yang0/handraw-style](https://github.com/yang0/handraw-style)（作者 yang0，v1.8.5）。
本包按其宽松许可安装于 CrabPaw 内置技能库；**作者署名与原仓库地址必须随本技能保留**。
本文件是 CrabPaw 适配版入口，操作契约继承上游 `SKILL.md`（见 `subskills/handdraw-style-prompter/SKILL.md`）。

## 与上游包的差异（先读这段）

1. **未随附 `images/` 参考图库与可浏览画廊**（53MB，体积原因）。激活判定一律走"名称+特征"路径；上游策略中"需要参考图"的分支按下方《激活策略（适配）》诚实降级——告知用户限制，**绝不虚构参考图**。
2. **文档内路径换算**：上游文档中所有 `skills/handdraw-style-prompter/...`、`skills/<子技能>/...` 形态的相对路径，在本包内一律按 `subskills/...` 解析（例如 `subskills/handdraw-style-prompter/references/model_capabilities.json`）。
3. **默认出图（与上游最大差异）**：提示词构造完成后**默认直接调用本机配置的图像模型出图**（见《CrabPaw 出图直连》）；上游"只出提示词、复制到 Midjourney 等外部工具"的行为仅在用户显式要求"只要提示词/不要出图"时采用。

## 参考表按需读取指南（不要整读大文件）

- **风格 #001–#327**：先 `Read` 本目录 `STYLES.md`（全库索引，2.5KB）建立认知；定位具体风格用 `Grep` 在 `styles_200_reorganized.md`（87KB，权威内容）中按编号锚点检索（如 `^## 041`），再 `Read` 对应段落。**严禁把该文件整段读入上下文。**
- **排版图型 SC-001~SC-023 / IG-001~IG-035 / SB-001~SB-071 / IP-001~IP-013 / EC-001~EC-024**：权威内容是单文件——`Read` `subskills/handdraw-style-prompter/references/layouts/<ID>.md`（共 166 个，一图一文件）。索引在 `references/layouts.json`。
- **主题色 C-01–C-36**：`Read` `COLORS.md`（12KB，可整读）。
- **模型激活判定**：`Bash` 执行
  `python subskills/handdraw-style-prompter/scripts/resolve_reference.py --model <模型名> --style <风格编号>`
  输出 JSON（activation_source / prompt_traits / reference_path），对未知模型**不猜测**能力。

## 默认模式

默认流程 = 按下述策略完成风格/配色/排版决策与提示词构造后，**直接调用本机配置的图像模型出图**（经 `ImageGenerate` 工具，走 config 的 `imageGeneration.provider`，当前为 Agnes Image 2.5 Flash；可用 `ImageGenerate action=list` 查询可用 Provider 与默认模型）。出图的同时在回复中完整附上中英提示词，用户随时可复制到 Midjourney/GPT Image 等外部工具复现。

仅当用户显式要求"只要提示词 / 先不出图 / 别生成"时，才退回上游默认——只产出提示词并说明可粘贴到任意生图 AI。

### 智能推荐策略（核心准则：每次由 AI 实时动态判断，严禁写死）

- **实时动态研判**：严禁维护任何"主题关键词 → 固定风格/颜色编号"的静态映射（严禁一见节气/传统就推 268、一见科技就推 011/054）。
- **全库开放式匹配**：每次推荐必须结合当前主题的深层语境、精神内核、视觉隐喻与画面构图，在 327 风格 × 36 主题色中实时开放式审美推理。
- **激发全库多样性**：同一主题在不同设计视角下有多种美学可能（"菜园"可以是水墨写意、田园木刻、粗粒油画棒、包豪斯几何……），按切入点灵活构思。
- **美学理由具象化**：推荐理由必须紧扣视觉隐喻与构图，说明笔触/质感与色彩情绪为何契合主题，杜绝套话。

组合规则：
1. **风格与色都未指定** → 推荐 1 组最优【风格编号 + 主题色编号】（色彩可单色统领/双色主辅/三色调和），给 1 句具象化理由，直接输出完整提示词。
2. **只指定风格** → 保留用户风格，动态推荐协调的主题色搭配。
3. **只指定主题色** → 保留用户色，动态推荐契合的手绘风格。
4. **两者皆指定** → 完全遵照用户指定。

## 激活策略（适配：无参考图库版）

以 `subskills/handdraw-style-prompter/references/model_capabilities.json` 解析当前模型（未指明默认 `gpt-image-2`，本库标定基线；未知模型一律按 unknown 安全兜底）：

- `name_activation=strong`（如 #042 Beatrix Potter、#011 David Shrigley、#269 苏联宣传画）：只用索引作者名 + 生成风格名 + 主题；**严禁**输出核心特征、图片路径或参考隔离块。
- 否则：附全部可用的正向核心特征（过滤含"避免/不要/不准/禁止"的子句）。
- **需要参考图的风格（本包降级规则）**：参考图资源未随包发布。此时：
  1. 按名称 + 特征生成正常提示词；
  2. 明确告知用户："本环境未安装 #<编号> 风格参考图库，提示词已按名称+特征路径生成；若需保真垫图，请到原仓库 `images/individual/` 目录获取该编号参考图"（附原仓库地址）；
  3. 绝不虚构、替代或编造参考图路径。

## CrabPaw 出图直连（默认出图通道）

默认流程——完成提示词构造后**立即出图**，不等用户额外确认：

1. 调用 `ImageGenerate` 工具（`action: "generate"`）：
   - `prompt`：最终中文提示词（含图文模式后缀/改图指令等，原样传入，**提示词内部严禁出现任何编号**——风格/图型/色号一律已转自然语言名称）；
   - **`enhance_prompt: false`**（必须）——本库提示词已按风格契约调优，工具层的通用 LLM 增强会稀释风格锚点、抹掉构图留白；
   - `aspectRatio`/`size`：按用户要求；未给则 `1:1`（封面/横幅类按用途给 `16:9` 等）；
   - 用户要多个方案时 `n: 2–4`（受 Provider 单请求上限约束，Agnes 为单图——多方案按分镜/变体逐张调用），或按摄影企划等子技能的分镜表逐张调用。
2. **改图/垫图请求**（用户上传照片要转手绘）：本机 `ImageGenerate` 暂不支持参考图上传——按排版工作流的固定转绘指令组装提示词后照常出图（写实转绘由生图模型按指令处理）；若效果不达预期，提示词可复制到支持垫图的外部工具（GPT Image/Midjourney/Flux）使用。
3. 生成后如实说明：使用了哪个 Provider/模型、哪条提示词、是否启用智能推荐组合；用户显式要求"只要提示词"时**不得**擅自出图。

## 输入

- 风格类请求缺省编号时按智能推荐策略补齐，**严禁因用户缺编号而中断或拒绝**。
- 排版类请求需要图型 ID（`SC-001` / `IG-001`…），风格/色缺省按智能推荐补齐。
- 用户要求提示词但没给主题：不追问，直接用占位符输出完整提示词（`【请在此输入画面主题，或在生图模型中垫入你的照片】`）。
- 编号/图型 ID/色号非法：请用户从索引中选择有效值，**不得编造编号**；用户未给画幅比时不擅自添加。

## 排版工作流

- 排版 ID 只决定**构图与文字结构**，不是画风。提示词文件原文使用，主题是唯一的内容来源。
- **两大架构分类**：
  1. **确定性静态排版**（绝大多数：SC/IG/SB/IP/EC 常规图型）——构图拓扑固定，直接提取 prompt 模板拼接画风与主题输出。
  2. **高维动态解析型**（代表 `SC-021` 自适应双拼照片转译）——必须由 AI 充当设计总监前置解析：分析照片视觉特征与情绪；构图语法严格轮替（【越界破框型】【微缩浮岛型】【记忆图谱平铺型】【经典悬浮落地型】【正负形咬合型】顺序轮替抽卡，严禁连续同玩法）；动态生成背景净化指令（40%–80% 纯净负空间）；严格画幅守恒（艺术区+原图严格 2 倍宽/高，各占 50%，中线无缝）；最终输出**单义、排他、强约束**提示词。
- **传图与改图规则**（传图永远可选，不强制）：
  - 未传图：纯文本直出，不阻断对话。
  - 传图/改图（写实转手绘）：为防机械叠加滤镜，提示词**必须**追加固定转绘重绘指令：
    `【请只提取人物的五官特征和姿态，场景轮廓，在画风上严格按 选择的风格 重新画，不要在原照片上加质感。】`
    （英文：`[Extract only the character's facial features and posture, and the scene contours. Strictly redraw from scratch according to the selected style; do not add texture or filters onto the original photo.]`）
- 选中排版 ID 即自动进入图文模式（电商 `EC-*` 除外：不加通用图文后缀、不主动拼画风）；标准排版 = 排版 prompt + 固定图文后缀叠加。排版请求中**不得**附加纯图模式提示语，不得把参考图路径/上传说明写进可复制提示词。
- 用户同时给风格编号：把风格的作者/名称、允许的正向特征、参考图策略与排版 prompt 组合（电商只在用户显式指定风格时拼画风）。
- 输出语言跟随用户主题（中文主题→中文；否则英文；混合输入按中文）。

## 提示词模式

默认 `pure-image`（纯图）。接受对话中的 `纯图模式` / `图文模式`。

- `pure-image`：保持现有工作流；回复末尾加小字 `当前处于纯图模式，可切换为图文模式。`
- `graphic-text`：主题原文照抄（`主题：` 之后不扩写、不改写、不解释）；在中英提示词**末尾逐字**追加（不翻译/不删减/不改序）：

  `【如果主题直白包含画面元素那就按主题出图，文案由你来升华，但是不要直接描述画面。 如果主题比较概念化，那么文案和主题尽量保持一致，如果文案较长由你提炼，由你先设计画面隐喻（人类和非人类都行）再出图   。    文字参与构图，图文一体】`

## 输出

对有效请求返回：

0. （若触发智能推荐）`💡 智能推荐组合：风格 #{编号} · {风格名} + 主题色 {色号} · {色名}` + 1 句具象化美学理由 + 可随时换编号的提示。
1. 所选风格：编号与风格名（核心特征按激活策略并入提示词，不单列）。
2. **中文提示词**：以 `风格名称：{风格名}。` 开头；有主题色时含 `主题色：{色名}。`；只描述用户主题与显式约束，附 `参考作者/风格名称` 标签；需要时附正向特征 `核心风格特征：…`；改图请求按上文固定指令追加。**提示词内部严禁包含任何编号（#018 / SC-021 / C-01 等）**。
3. **英文提示词**：以 `Style name: {generation_name}.` 开头，同样禁止编号，规则与中文对齐。
4. 简短说明：默认注明"已直连本机图像模型（{provider}/{model}）生成"，并附完整中英提示词供外部工具复现；用户只要提示词时改述为"提示词可粘贴到任意生图 AI"。

不发明视觉特征、不添加通用质量/构图话术、不加负面提示词；特征只描述渲染风格，不得替换/改变用户的主体、动作、场景或故事。
