# 📝 Summarize Pro — 文本摘要引擎

强大的 AI 文本摘要工具，支持多种格式，适配各种场景。

## 🚀 激活方式

当用户说以下关键词时自动激活：
- **"总结"、"摘要"** — 任何文本
- **"TL;DR"、"一句话总结"** — 快速概要
- **"要点"、"关键点"** — 核心内容
- **"行动项目"、"待办"** — 任务提取
- **"子弹要点"** — 列表格式
- **"执行摘要"** — 商业报告格式
- **"会议摘要"** — 含决策和待办
- **"邮件摘要"** — 邮件格式
- **"对比" + 两段文本** — 对比摘要
- **"ELI5"** — 简单解释
- **"保存摘要"** — 收藏摘要
- **"摘要历史"** — 查看历史

## 📊 支持的摘要格式

### 1. TL;DR（一句话总结）
```
🔥 TL;DR
━━━━━━━━━━━━━━━━━━
[1-2句话概括核心内容]
```

### 2. 子弹要点（3-7条）
```
📋 KEY POINTS
━━━━━━━━━━━━━━━━━━
• [要点1]
• [要点2]
• [要点3]
```

### 3. ELI5（简单解释）
```
🧒 ELI5
━━━━━━━━━━━━━━━━━━
[用简单的语言和类比解释复杂内容]
```

### 4. 执行摘要（商业报告）
```
📊 EXECUTIVE SUMMARY
━━━━━━━━━━━━━━━━━━
**概述:** [1-2句话]
**关键发现:** • [发现1] • [发现2]
**建议:** [下一步行动]
```

### 5. 对比摘要
```
⚖️ COMPARISON
━━━━━━━━━━━━━━━━━━
| 方面 | A | B |
|------|---|---|
| 主要观点 | ... | ... |
```

### 6. 会议摘要
```
🤝 MEETING SUMMARY
━━━━━━━━━━━━━━━━━━
**主题:** [会议主题]
**讨论:** • [要点1] • [要点2]
**决策:** • [决定1]
**待办:** □ [任务] - [负责人]
```

### 7. 邮件摘要
```
📧 EMAIL SUMMARY
━━━━━━━━━━━━━━━━━━
**发件人:** [姓名]
**目的:** [邮件目的]
**关键点:** • [要点]
**紧急程度:** 🔴高 / 🟡中 / 🟢低
```

### 8. 行动项目
```
✅ ACTION ITEMS
━━━━━━━━━━━━━━━━━━
□ [任务1] — [负责人] — [截止日期]
□ [任务2]
```

### 9. 渐进摘要
同时输出多个层次：
```
📝 PROGRESSIVE SUMMARY
🔥 TL;DR: [一句话]
📋 短版(3条): • [要点]
📄 完整版: [段落]
```

### 10. 章节摘要
适合书籍、报告章节：
```
📖 CHAPTER SUMMARY
━━━━━━━━━━━━━━━━━━
**概要:** [2-3句概述]
**关键事件:** 1. [事件1] 2. [事件2]
**重要细节:** • [细节]
```

## 📈 输出统计

每个摘要都会显示：
```
📊 [原始字数] → [摘要字数] ([压缩率]%)
```

## 💡 智能格式检测

如果用户没有指定格式，系统会自动选择最佳格式：

| 内容类型 | 自动格式 |
|---------|---------|
| 短文本 (<100字) | TL;DR |
| 邮件 | 邮件摘要 |
| 会议记录 | 会议摘要 |
| 新闻文章 | 子弹要点 |
| 商业报告 | 执行摘要 |
| 对比内容 | 对比摘要 |
| 任务文本 | 行动项目 |

- ✅ 无 API 调用
- ✅ 数据不外传
- ✅ 支持历史记录保存
