# 📽️ HTML Presentation — 网页演讲演示文稿

## 能力

- 🎨 **36 套主题**（极简/商务/科技/暗色/杂志/小红书等）
- 🧩 **31 种布局**（封面/内容/双栏/数据/KPI/流程图/引用/时间线/总结等）
- ✨ **47 种动效**（27 CSS + 20 Canvas FX）
- 📊 **Chart.js 原生支持**（柱状图/折线图/饼图/雷达图）
- 🎤 **演讲者模式**（S 键弹出提词器 + 下一页预览 + 计时器）
- ⌨️ **键盘导航**（← → 翻页，F 全屏，T 切换主题）

## 快捷键

| 键 | 功能 |
|----|------|
| ← → | 翻页 |
| S | 演讲者模式 |
| T | 切换主题 |
| F | 全屏 |
| O | 幻灯片概览 |
