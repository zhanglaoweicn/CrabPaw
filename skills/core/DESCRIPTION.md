# 核心机制技能

本分类包含 CrabPaw 的核心机制技能，提供记忆管理、自我改进、技能创建等系统级基础功能。

## 技能列表

| 技能名称 | 功能说明 |
|----------|----------|
| self-improving-agent | 自我改进智能体，支持从经验中学习 |
| skill-creator | 技能创建指南，支持 SKILL.md 编写、验证打包 |
| prompt-engineering-expert | 提示词工程专家，提供提示词优化建议 |

## 使用场景

- 需要长期记忆存储和检索
- 持续学习和自我优化
- 创建新技能或优化提示词
- 情感交互和陪伴
