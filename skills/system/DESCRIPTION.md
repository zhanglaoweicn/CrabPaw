# 系统与自动化技能

本分类包含系统管理和自动化技能，提供系统监控、文件管理、浏览器/桌面自动化等功能。

## 技能列表

| 技能名称 | 功能说明 |
|----------|----------|
| system-info | 系统信息，查询系统配置和状态 |
| healthcheck | 健康检查，检查系统和服务状态 |
| file-manager | 批量文件操作、智能分类、去重、同步 |
| browser-use | 浏览器自动化，网页导航/表单/截图 |
| agent-browser | 无头浏览器，Accessibility Tree，AI Agent 优化 |
| desktop-control | 桌面自动化，鼠标/键盘/截图/窗口 |
| windows-ui-automation | Windows UI 自动化，PowerShell 控制 |

## 使用场景

- 系统状态监控和安全审计
- 文件批量管理和整理
- 浏览器自动化操作
- 桌面应用自动化控制
