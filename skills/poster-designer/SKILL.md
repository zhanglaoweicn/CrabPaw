# 营销海报设计工作流

目标用户是中小企业老板。三类刚需：**产品/业务宣传海报、节日营销海报、客户问候海报**。

## 工作流（按顺序执行）

### 第 0 步：读取品牌资产包
先调 `PosterBrandKit {action:"get"}`。品牌包里有企业名/slogan/电话 → 海报自动携带；
若为空且用户未提供联系方式，**先问用户要**（或让用户口述后 `PosterBrandKit {action:"set"}` 存下来——一次录入终身复用）。

### 第 1 步：明确需求（缺什么问什么）
- 海报类型：product / festival / greeting（决定 template_id）
- 主标题 + 2-4 条卖点（用户没说就按产品/主题帮写，但**价格和电话必须来自用户或品牌包，不许编造**）
- 比例：朋友圈 1:1 / 抖音 9:16 / 小红书 3:4（默认 1:1）

### 第 2 步：调用 PosterGenerate
参数要点：
- `bg_prompt`：描述**无文字的背景氛围**（如"深蓝科技感渐变，霓虹光斑，留出左上视觉重心"）——底图永远不要文字
- 有产品照片 → 传 `product_image_path`（产品会自动抠图/原样合成，**不要让 AI 重绘产品**）
- 文案来自第 1 步，电话/价格/日期**一个字都不能错**

### 第 3 步：交付与迭代
- 出图后告诉用户路径，并主动说明可以：改文案（只重排版）、换底图（只重生成底图）、加比例变体
- 用户要"发给我" → 找到产物路径后用 SendWecomFile（企微）或直接展示

## 铁律

1. **产品保真**：产品照片原样合成，禁止让 AI 重绘产品本体
2. **文字保真**：电话/价格/日期/地址只出现在 HTML 排版层（PosterGenerate 的 title/subtitle/bullets/price 参数），绝不写进 bg_prompt
3. **品牌一致**：联系信息优先取品牌包，用户没给就问，不要编造
4. **诚实降级**：底图生成失败时说明"用了纯色渐变底"，不假装成功
