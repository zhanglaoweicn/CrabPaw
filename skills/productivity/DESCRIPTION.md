# 生产力工具技能

本分类包含生产力工具技能，提供文档处理、文本摘要、信息检索等功能，帮助提升工作效率。

## 技能列表

| 技能名称 | 功能说明 |
|----------|----------|
| excel-xlsx | Excel 工作簿创建/编辑/公式/格式 |
| word-docx | Word 文档创建/编辑/样式/批注 |
| powerpoint-pptx | PPT 创建/编辑，布局/模板/占位符 |
| pdf-generator | 从 Markdown/HTML/数据生成专业 PDF |
| pdf-to-word-docx | PDF/图片转 Word/Excel/PPT 等 10 种格式 |
| markdown-converter | 文档转 Markdown，便于 LLM 处理 |
| summarize-pro | 智能摘要，20 种格式，本地处理 |
| multi-search-engine | 国内多搜索引擎集成 |
| wechat-article-search | 微信公众号文章搜索 |
| wecom-daily-news | 企微每日资讯推送 |
| weather | 天气查询 |

## 使用场景

- 文档生成和处理（Excel/Word/PPT/PDF）
- 文档格式转换和 Markdown 化
- 信息检索和摘要
- 日常查询（天气、搜索、资讯）
