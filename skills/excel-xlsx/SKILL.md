# Excel 工作簿技能

当主要产物是 Microsoft Excel 工作簿或电子表格文件时使用此技能，尤其当公式、日期、格式、合并单元格、工作簿结构或跨平台行为很重要时。

## 何时使用

- 任务涉及 Excel、`.xlsx`、`.xlsm`、`.xls`、`.csv` 或 `.tsv`
- 公式、格式、工作簿结构或兼容性很重要
- 文件在编辑后必须保持可靠

## 核心规则

### 1. 按工作选工具，而非按习惯

- 使用 `pandas` 进行分析、重塑和 CSV 类任务
- 使用 `openpyxl` 当公式、样式、工作表、批注、合并单元格或工作簿保留很重要时
- 将 CSV 视为纯数据交换格式，而非 Excel 功能完整的格式
- 读取值、保留活工作簿和从零构建模型是不同的电子表格工作

### 2. 日期是带历史遗留问题的序列号

- Excel 将日期存储为序列号，而非真正的日期对象
- 1900 日期系统包含虚假闰日 bug（2月29日1900），某些工作簿使用 1904 系统
- 时间是小数天数据，所以格式化和转换都很重要
- 日期正确但数字格式仍显示错误，对用户来说就是不对

### 3. 当工作簿应保持活跃时，将计算留在 Excel 中

- 将公式写入单元格，而非硬编码 Python 计算的派生结果
- 使用对假设单元格的引用，而非公式中的魔术数字
- 缓存的公式值可能过期，编辑后不要盲目信任
- 交付前检查复制公式的错误范围、错误工作表和静默的偏移漂移
- 绝对引用和相对引用是逻辑的一部分，复制的公式即使"能用"也可能是错的
- 在整个区块填充前，先在几个代表性单元格上测试新公式
- 交付前验证分母、命名范围和前驱单元格
- 工作簿应以零公式错误交付，不应留有 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?` 或循环引用让用户修复
- 对于模型类工作，在批注或附近备注中记录非显而易见的硬编码、假设或源输入

### 4. 在 Excel 破坏数据类型之前保护它们

- 长标识符、电话号码、邮编和前导零值通常应存储为文本
- Excel 静默截断超过 15 位的数值精度
- 混合文本-数字列在读取和写入时需要显式处理
- 科学记数法、自动解析日期和去除前导零是常见的数据损坏，不是外观问题

### 5. 在更改内容之前保留工作簿结构

- 现有模板优先于通用样式建议
- 合并区域只有左上角单元格存储值
- 隐藏行、隐藏列、命名范围和外部引用仍可能影响公式和输出
- 共享字符串、定义名称和工作表级约定即使可见单元格看起来简单也可能重要
- 为新填充的单元格匹配样式，而非静默引入新的视觉系统
- 如果工作簿是模板，保留工作表顺序、列宽、冻结、筛选、打印设置、验证和视觉约定
- 条件格式、筛选、打印区域和数据验证通常承载业务含义
- 如果没有现有样式指南且文件是模型，保持可编辑输入在视觉上可区分于公式，但不要覆盖已建立的模板来强制通用风格

### 6. 交付前重算和审查

- 如果收件人需要当前值，仅公式字符串不够
- `openpyxl` 保留公式但不计算它们
- 验证无 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?` 或循环引用残留
- 如果布局重要，在宣布完成前渲染或视觉审查工作簿
- 注意读取模式：仅为值打开工作簿然后保存可能将公式扁平化为静态值
- 如果假设或硬编码覆盖必须保留，使其足够明显以便下一个编辑者可以审计

### 7. 按文件规模调整工作流

- 大型工作簿可能因内存飙升、填充空行和缓慢的全表读取而失败
- 当文件大到一次性加载变得脆弱时，使用流式或分块读取
- 大文件工作流还需要更窄的读取、显式 dtype 和工作表定位以避免意外损坏

## 常见陷阱

- 读取时的类型推断可能将数字留为文本或将 ID 转换为损坏的数值
- 列索引因工具而异，生成公式中偏移一错误很常见
- 单元格中的换行需要设置自动换行才能正确显示
- 源文件移动时外部引用容易断裂
- 旧版 Excel 工作流中的密码保护不是真正的安全
- `.xlsm` 可能包含宏，`.xls` 仍是更紧凑的旧版格式
- 大文件可能需要流式读取或更谨慎的内存处理
- Google Sheets 和 LibreOffice 可能与 Excel 不同地重新解释日期、公式或样式
- 动态数组或较新的 Excel 函数如 `FILTER`、`XLOOKUP`、`SORT`、`SEQUENCE` 可能在旧版查看器中失败或降级
- 工作簿可能看起来正常但仍携带上次重算的过期缓存值
- 以错误的工作簿视图保存可能将公式替换为缓存值并静默破坏活模型
- 不检查相对引用就复制公式可能将一个错误范围推到整个区块
- 隐藏工作表、命名范围、验证和合并区域通常承载快速浏览时不可见的业务逻辑
- 工作簿可能数值正确但因筛选、条件格式、打印设置或数据验证被剥离而失败
- 工作簿可能数值正确但因自动换行、裁剪标签或窄列从未审查而视觉上失败

## 中国财务报表规范

### 常用财务报表模板

**资产负债表：**
- 货币单位：元/万元/亿元，表头注明
- 金额格式：千分位分隔，负数用红色或括号表示
- 行次：连续编号
- 列结构：期末余额 | 期初余额

**利润表：**
- 期间：本年累计金额 | 本月金额
- 营业收入→营业成本→毛利→各项费用→营业利润→利润总额→净利润
- 同比/环比增长率可附列

**现金流量表：**
- 三大分类：经营活动/投资活动/筹资活动
- 净额 + 期初余额 = 期末余额

### Excel 财务建模注意事项

**公式规范：**
- 输入单元格使用蓝色字体，公式单元格使用黑色字体
- 假设输入集中在独立工作表（"假设"或"Parameters"）
- 关键公式添加单元格批注说明逻辑
- 避免硬编码数字嵌入公式，使用单元格引用

**日期处理：**
- 中国财务年度：1月1日 - 12月31日
- 报告期格式："2024年Q1"、"2024年1-6月"
- 使用 `DATE()` 函数而非文本日期

**数字格式：**
- 金额：`#,##0.00` 或 `#,##0`（万元时）
- 百分比：`0.00%`
- 增长率：`+0.00%;-0.00%`（正绿负红）
- 大数：使用万/亿单位，`0.00,"万"` 或 `0.00,,"亿"`

**工作表命名规范：**
- 封面 / 目录
- 假设 / Parameters
- 利润表 / P&L
- 资产负债表 / B/S
- 现金流量表 / CF
- 分析 / Analysis
- 数据源 / Data

**打印设置：**
- 页面：A4 横向
- 页眉：公司名称 | 报表名称
- 页脚：第 X 页 / 共 Y 页 | 打印日期
- 重复标题行

## 交付清单

每次 Excel 工作簿交付前检查：

- [ ] 无公式错误（#REF!/#DIV/0!/#VALUE!/#NAME?）
- [ ] 公式使用单元格引用而非硬编码数字
- [ ] 日期正确存储和格式化
- [ ] 长ID/电话号码存储为文本
- [ ] 合并单元格值在左上角
- [ ] 隐藏行列/命名范围/验证完整
- [ ] 条件格式和筛选保留
- [ ] 缓存值已刷新
- [ ] 数字格式正确（千分位/百分比/万/亿）
- [ ] 打印设置正确
- [ ] 输入单元格与公式单元格视觉区分
- [ ] 至少一次视觉审查
