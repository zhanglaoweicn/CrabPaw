CrabPaw U 盘版 · 开箱指引

插上就能用的 AI 员工团队 · 数据存在 U 盘里，不上传、不联网存储
⏱ 首次配置约 15 分钟 · 全程 6 步 · 卡住就发售后群截图
1

插上 U 盘

把 U 盘插进电脑任意 USB 口（建议插 USB 3.0 及以上接口——通常是电脑上带蓝色胶芯的口，速度快很多）。

打开「此电脑」，你会看到一个新盘符（比如 E:）。双击打开它。

2

启动 CrabPaw

找到 CrabPaw.exe，双击它。

首次启动请耐心等 1-2 分钟——程序在准备数据环境，只慢这一次。

⚠ 弹出蓝色「Windows 已保护你的电脑」？
这是系统对所有新程序的例行提示（本程序未购买数字签名）。点击 「更多信息」→「仍要运行」 即可。
⚠ 360 / 电脑管家等杀毒软件拦截？
选择 「允许」或「添加信任」。本程序不联网上传你的任何数据。
3

跟着首次向导走

第一次启动会出现设置向导，共 4 小步：

向导步骤怎么处理
1. 激活 CrabPaw先跳过——填 Key 我们下面专门讲（也可以现在就填）
2. 设置唤醒词直接下一步（默认「小螃蟹」，想改就改）
3. 试听音色可以点试听选一个喜欢的，也可以下一步
4. 一体机模式直接跳过——只给「前台常驻一体机」用，普通电脑不需要
⚠ 第 4 步「开机自启」不要勾
除非这台电脑专门当前台设备。勾了会全屏待机、不易退出。
⚠ 飞书 / 企业微信 通道整段跳过
那是企业多端同步的进阶功能，个人使用不需要填写。
4

拿到三把钥匙（模型 Key）

CrabPaw 本身是「团队指挥系统」，能力分三类，每一类去不同的地方拿钥匙。建议先都注册好、复制保存下来，下一步一次填完。

🔑 钥匙一 · 文字对话大脑（必配）
平台去哪拿
DeepSeek（推荐，便宜好用）打开 platform.deepseek.com → 注册 → 左侧「API keys」→ 创建并复制（sk- 开头）
火山方舟 · 豆包（可选）打开 console.volcengine.com/ark/ → API Key 管理 → 创建
💡 充值建议
DeepSeek 充 10 元能用很久。
🎙 钥匙二 · 语音（说话和听你说话，推荐配）
平台去哪拿
火山引擎 · 语音技术打开 console.volcengine.com/speech/ → 开通语音服务 → 获取豆包语音 API Key（识别与合成共用这一把，只填一次）
⚠ 别找错地方
语音的 Key 和图片视频的 Key 不在同一个地方拿——语音在「语音技术」，图片视频在「方舟」。
💡 建议
语音是这款产品的灵魂（按住空格直接聊），强烈建议配。
🖼 钥匙三 · 图片与视频生成（选配）
平台去哪拿
火山方舟（Ark）打开 console.volcengine.com/ark/ → API Key 管理 → 创建 Key，并开通图片/视频生成模型
💡 建议
不常生成图片视频可以先不配，要用时再来填。
5

把钥匙填进应用

先找到管理舱：在主界面 右上角工具栏，找到那个小方块图标（鼠标悬停显示「系统管理」），点它打开设置面板。

打开后左侧是分类菜单，点 「模型配置」，三把钥匙各回各家：

  • 钥匙一（文字大脑） → 找到对应服务商卡片（如 DeepSeek）填入
  • 钥匙二（语音） → 语音服务（豆包） 卡片 → 填入（识别/合成/实时对话共用这一把）
  • 钥匙三（图片视频） → 图片生成 / 视频生成 卡片 → 填入
💡 更省事
也可以直接在对话里对 AI 说「打开设置」或「打开管理舱」，它会帮你打开。

填完点保存。

6

说句话试试！

两种说话方式，任选一种（向导里设置过唤醒词）：

方式怎么用适合场景
按住空格按住空格键说话，松手发送随手一问、旁边有人时
唤醒词直接说「小螃蟹，明天天气怎么样」双手忙时
⚠ 记得先点左下角语音球
灰色=静音（没有声音），点一下变亮即开启。

试试说：「明天天气怎么样？」

看到它回复并开口说话——恭喜，你的 AI 团队正式上岗！

✨ 试试这些玩法
「接通财务顾问」召唤专家一对一咨询 ｜ 「开个圆桌会讨论下个月的计划」多位专家群聊讨论给你决策卡 ｜ 「把这份文档转成 Word」文件生成 ｜ 「每天早上 8 点给我播报经营简报」让它主动找你
🛡

数据安全（请务必读）

  • 你的所有数据（对话/记忆/文件）都存在这个 U 盘里，不经过任何第三方服务器——这是本产品最大的特点，请像爱护钱包一样爱护它。
  • 定期备份：把 U 盘里的 CrabPaw-Data 文件夹复制一份到你的电脑上（建议每周一次）。U 盘有丢失和损坏的可能。
  • 拔 U 盘前必须先退出程序：点击窗口右上角 ✕ 完全退出，等 10 秒，再点击系统托盘的「安全弹出硬件」。直接拔盘可能导致数据损坏。
  • 若提示「设备在使用中」：双击 U 盘根目录的「安全退出.bat」，再弹出。

常见问题

按空格没反应？
检查 Windows 设置 → 隐私 → 麦克风 → 允许桌面应用访问麦克风。另外确认语音球不是灰色静音态——点击语音球可切换。
语音回复没有声音？
左下角语音球如果是灰色（静音态），点击它开启。
程序被杀毒软件删掉了？
到杀毒软件的「恢复区/信任区」恢复文件并添加信任，然后重新双击 CrabPaw.exe。
怎么更新到新版本？
售后群会发布新版本包，按群里附带的《版本更新指引》三步完成——你的对话和数据在 CrabPaw-Data 文件夹里，覆盖不会影响它们。
更多功能怎么学？
售后群每周有使用技巧分享；也可以直接问它本人：「你能做什么？」——它会给你完整清单。
