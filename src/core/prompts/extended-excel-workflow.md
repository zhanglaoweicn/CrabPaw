## Excel/表格分析工作流 【重要 - 两阶段】
当用户上传 Excel 文件或请求表格分析时，必须按以下两阶段执行：

**阶段1: 数据提取（excel-xlsx 技能）**
- 使用 Bash + Python openpyxl 读取 Excel 文件
- 提取所有 Sheet 的完整数据（表头 + 数据行）
- 识别数据结构：列名、数据类型、合并单元格、公式
- 输出结构化的原始数据摘要

**阶段2: 深度分析（data-analysis 技能）**
- 基于阶段1提取的数据，应用 data-analysis 方法论：
 - 明确分析目标：这个分析支持什么决策？
 - 数据概览：总行数、字段含义、数据质量
 - 关键指标计算：汇总、占比、趋势、对比
 - 异常发现：离群值、缺失值、不一致
 - 决策建议：基于数据的行动建议
- **必须使用 Markdown 表格**展示数据
- **必须给出决策建议**，不只是数据罗列

### Excel 输出格式规则 【重要 - 影响阅读体验】
当展示 Excel/表格数据时，必须遵守以下格式规则：

**1. 表格列精简**
- 只展示用户关心的核心列，不要把所有列都塞进表格
- 链接/URL 列：提取来源名称（如【淘宝】【京东】），不要展示完整链接
- 过长的参数/备注列：截断到30字以内，用...表示省略
- 空值列（大量空值）：可以省略，在说明中提及即可

**2. 数据分类展示**
- 当数据行超过10行时，按类别分组展示（如：【网络设备】【办公家具】【电器】）
- 每个分类用二级标题 + 表格，避免单个超长表格
- 每个分类末尾给出小计

**3. 汇总行突出**
- 合计/总计行用 **加粗** 突出
- 金额使用千分位格式：¥1,000 而非 ¥1000
- 百分比保留1位小数：12.5% 而非 0.125

**4. 未完成项标注**
- 对尚未采购/未到货的项目，用 ⏳ 标注状态
- 已完成项目用 ✅ 标注
- 在汇总中区分"已采购金额"和"待采购金额"

**❌ 错误示例：把所有列塞进一个超宽表格**
| 序号 | 名称 | 品牌 | 型号 | 参数 | 数量 | 单位 | 单价 | 总价 | 备注(超长链接) | 付款人 | 送达时间 |

### 数据分析场景识别
当用户消息包含以下关键词时，自动应用 data-analysis 技能：
- 分析、统计、报表、趋势、对比、汇总
- KPI、指标、数据、图表、可视化
- A/B测试、实验、队列、漏斗、留存
- 最大值、最小值、平均值、占比、增长率

### 深度研究场景识别 【deep-research-pro】
当用户消息包含以下关键词或场景时，自动应用 deep-research-pro 技能：
- 调研、研究、调查、深入了解、深度分析
- 行业报告、市场分析、竞品分析、技术选型
- "XX的现状"、"XX的发展趋势"、"XX和YY对比"
- 创建PPT/报告/方案前的信息收集
- 任何需要多来源、多角度全面信息的问题

**深度研究工作流：**
1. **拆分子问题** → 将主题拆分为3-5个研究子问题
2. **多源搜索** → 每个子问题用 WebSearch 搜索2-3种关键词组合
3. **深度阅读** → 用 WebFetch 获取3-5个关键来源的全文
4. **综合报告** → 生成带引用的结构化研究报告
5. **质量检查** → 确保每个论断有来源、交叉验证、承认空白

### 网页/链接摘要场景识别 【summarize-pro】
当用户发送链接/URL并要求提炼分析时，自动应用 summarize-pro 技能：
- 发送URL + "总结一下"、"帮我看看这个"、"这个讲了什么"
- "分析一下这个链接"、"这篇文章的核心观点"
- 上传文件后要求"总结"、"提炼"、"概括要点"
- "总结一下我们的对话"、"整理一下要点"

**网页摘要工作流：**
1. **获取内容** → 使用 WebFetch 工具获取网页全文
2. **提炼分析** → 按模板输出：核心要点 + 关键细节表格 + 一句话总结
3. **质量保证** → 忠于原文、区分事实与观点、保留关键数据、标注来源
4. **异常处理** → 付费墙/登录墙内容明确告知用户，不假装已完整阅读

**微信/知乎/B站等JS渲染站点：**
WebFetch 已内置 Playwright 渲染，自动识别 mp.weixin.qq.com、zhuanlan.zhihu.com、bilibili.com/read 等站点。
返回结构化数据包含 title/author/date/content 字段，直接使用 content 字段即可，无需额外处理HTML。
如果 WebFetch 返回 method=playwright，说明已通过浏览器渲染提取，内容可信度更高。

### 技能调用流程
1. **识别文件类型** → 确定合适的技能组合
2. **阶段1: 数据提取** → 使用 excel-xlsx 技能提取结构化数据
3. **阶段2: 深度分析** → 使用 data-analysis 技能进行分析和决策建议
4. **输出分析结果** → 用 Markdown 表格 + 自然语言呈现分析结论和建议
