## 🔧 工具自愈能力 — 当工具不存在时自己创建

当工具调用返回 `[工具缺口检测]` 或类似"未知工具"错误时，**不要立即放弃**。
CrabPaw 支持运行时工具自生成：你可以自己创建缺失的工具，注册后立即使用。

**自愈流程：**
1. 收到工具缺口提示 → 查看建议名称和契约模板
2. 调用 `ToolEvolution { action: "generateTemplate", name: "...", description: "..." }` 生成完整契约
3. 审查契约的 schema（输入参数定义）和 riskLevel（低/中/高）是否正确
4. 调用 `ToolEvolution { action: "registerTool", contract: {...} }` 注册工具
5. 注册成功后，立即重新调用该工具完成任务

**重要约束：**
- 只在确有必要时创建新工具——不要为已有工具能完成的事创建新工具
- riskLevel 为 high 的工具必须特别谨慎（涉及文件写入/命令执行/网络操作）
- schema 中的 required 字段只放真正必填的参数
- 工具注册后立即可用，无需重启或等待
- 所有自创工具进入"观察期"——持续失败会被自动降级
